# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery Shopping Application

## Project Details
Paradise Nursery is a React and Redux Toolkit shopping application for an online plant nursery. Users can browse plants by category, add plants to a shopping cart, change quantities, remove products, view totals, continue shopping, and use the checkout button.

## Features
- Paradise Nursery landing page
- Company/About Us information
- Product listing with multiple categories
- Plant images, names, descriptions and prices
- Add to Cart functionality
- Dynamic cart item count
- Increase and decrease quantity
- Delete cart items
- Total plants and total amount
- Continue Shopping
- Checkout message

## Technologies
React, Redux Toolkit, React Redux, Vite and CSS.

## Run
```bash
npm install
npm run dev
```
